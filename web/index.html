    METHOD & PROVENANCE

    计算方法与指标口径

    可追溯的 RTKLIB 计算

    使用官方 2.4.3 b34 的广播星历、坐标变换、载频和 dops()。OBS 单独按原始字段读取，以保留空相位上的 LLI。支持 RINEX 3.x OBS 与 RINEX 2/3 NAV。

    时序可见性与平均 C/N0

    可见性指有非零数值观测的卫星记录，不是理论可见卫星或 RTK 实际解算卫星。C/N0 是有效 S 字段在 dB-Hz 域的算术均值；默认混合所有观测信号，可在信噪比页面选择具体信号。空值不填零，表格提供样本数。

    GF / MW / LLI：独立判据，事件去重

    使用固定信号对；默认按相位覆盖率选取每个频带的信号。GPS 以 L1、GLONASS 以 G1、Galileo 以 E1、北斗优先 B1I 为锚，分别与其他频带组合。GLONASS 使用槽号载频。仅在连续、相邻且相位有效的历元比较：

    GF = λ₁L₁ − λ₂L₂
    MW = c(L₁ − L₂)/(f₁ − f₂) − (f₁P₁ + f₂P₂)/(f₁ + f₂)

    GF 和 MW 的历元差超过各自阈值时标记；两者均为米。LLI 在有效相位上按 bit0（失锁）或 bit1（半周不确定）标记。空相位 LLI 单列。不同信号、不同判据触发同一卫星同一历元，仅合计一个候选事件。候选事件不等于已确认周跳。

    PDOP

    采用 RTKPLOT 的四参数、单公共钟差几何模型，使用有观测、健康广播星历且达到高度角截止的卫星。少于四星或几何奇异时输出缺测。此数值不等于另估系统间钟差后的多系统 SPP 精度。站址默认为 OBS 头部坐标，缺失时尝试单点定位；当前采用固定站址，不适合长距离运动轨迹。

    多路径 MP1 / MP2

    α = (f₁/f₂)²
    MP1 = P₁ − λ₁L₁ − 2GF/(α − 1)
    MP2 = P₂ − λ₂L₂ − 2αGF/(α − 1)

    参考 RTKPLOT UpdateMp() 的组合。按信号对在缺测、时间间隔、接收机事件或任一周跳判据处断弧，再去除各弧均值；不足最短弧长的样本不进入 RMS。与原版 RTKPLOT 的分弧规则有区别。MP 含码噪声等误差，不是纯环境多路径。跨组合 RMS 仅作描述，比较站点时应固定信号与样本条件。

    源代码与结果

    计算使用全部原始历元。缩放仅影响显示，CSV / JSON 导出保留完整样本、阈值与文件 SHA-256。数据有缺口或没有可用星历时明确提示。
